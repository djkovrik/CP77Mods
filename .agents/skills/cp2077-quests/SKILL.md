# Cyberpunk 2077 · квесты

Начинай с требуемого события и состояния конкретного сохранения. Выбери владельца прогресса: запущенная игрой фаза графа, fact или сохраняемая система мода. Определи, кто принимает сигнал, что игрок увидит и что произойдёт при повторной загрузке посередине стадии.

Redscript с Codeware, патчи ArchiveXL и прямая правка игровых ресурсов — равнозначные подходы. Выбирай для конкретного изменения по тому, где доступен нужный сигнал, кто восстановит стадию при загрузке и какие ресурсы мод разделит с другими модами.

| Подход | Когда подходит |
| --- | --- |
| Redscript + Codeware | Нужны данные живой сессии, готовность HUD, динамическое содержание или точечная коррекция при загрузке ресурса. Учитывай срок жизни подписки и цену периодических проверок. |
| ArchiveXL | Требуется добавить собственную фазу в существующий граф, зарегистрировать журнал или подключить мировые ресурсы через поддерживаемую секцию. Проверь родителя, якорь и поведение на старом сейве. |
| Прямая работа с CR2W | Требуется выразить ожидание, развилку или сцену средствами движка либо изменить конкретную существующую фазу. Для замены по ванильному depot path проверь другие моды, поставляющие тот же файл. |

Сочетай подходы, когда они решают разные части задачи. Например, граф владеет ожиданием прибытия, ArchiveXL подключает фазу к кампании, а скрипт отвечает за готовность телефона к показу баннера. У каждого перехода и одноразового эффекта должен быть один владелец.

- **Найти исполнителя.** Проследи от фактической `.gamedef` до `.quest`, фазы и сцены. Для заказа фиксера или события района начни с агрегатора открытого мира. [Карта базовой игры и Phantom Liberty](references/depot.md)
- **Обработать событие из скрипта.** Используй события сессии и игровые системы для старта, стадий, условий и одноразовых действий. Для точечного изменения существующего ресурса рассмотри фильтрованный `Resource/PostLoad`. [Старт, повторение, исправления и API](references/runtime.md)
- **Добавить авторскую фазу или изменить маршрутизацию.** Для прибытия в зону, ожидания fact, постановки сцены или смены стадии проследи событие через граф и его мировые зависимости. [Типы, обе модели графа и сокеты](references/graphs.md)
- **Подобрать ванильный образец.** Для развилки звонка, передачи цели, отмены ожидания и параллельных фаз сверяй реальные входы и выходы. [Повторяющиеся схемы заданий](references/vanilla-patterns.md)
- **Выпустить ресурсный патч.** Для добавления фазы выбери родителя и якорь ArchiveXL. Для замены файла проверь исходный depot path, другие моды по тому же пути и содержимое собранного архива. [ArchiveXL и прямая правка CR2W](references/resource-patches.md)
- **Показать задание игроку.** Для SMS при загрузке проверь готовность телефонного HUD и однократную постановку баннера в очередь. Для отслеживаемой цели свяжи лист метки с узлом мира и активируй его через менеджер квестовых маркеров. [Журнал, маркеры, SMS и ответы](references/journal.md)
- **Написать текст задания.** Подбери голос рассказчика, момент открытия описания и действие для трекера. [Английские заголовки, описания и брифы](references/english-journal.md)
- **Поставить сцену или видеозвонок.** Проверь адреса сокетов сцены, ID исполнителя, ресурсы анимации и привязку реплики к субтитрам, голосу и мимике. [Сцены, диалог и холозвонки](references/scenes-and-dialogue.md)
- **Связать квест с миром.** Для community, патруля NPC, управляемой двери или читаемого чипа проследи цепочку от квестовой команды до объекта мира. [Участники, маршруты и предметы](references/world-interactions.md)

Для ресурсов Cyberpunk 2077 2.5 используй WolvenKit CLI 10 или новее. Проверь версию используемого исполняемого файла через `--version`. Если структура старого экспорта вызывает сомнение, заново экспортируй исходный CR2W из архивов целевой версии игры.

Для исследования одного `.quest.json` или `.questphase.json` запусти из папки скилла `python scripts/quest_graph.py <export.json> --edges --sockets`. Требуется Python 3 и обычный вложенный CR2W JSON WolvenKit. Утилита читает один ресурс, проверяет RootChunk и вложенные phaseGraph, выводит ссылки на ресурсы и флаг Embedded. Содержимое Data.EmbeddedFiles исследуй отдельно. Ненулевой код означает ошибку чтения или структуры. Имена экспортов и API сверяй с версией игры и Codeware пользователя.

При проверке укажи отдельно, какие связи прослежены в данных, какие скрипты скомпилированы и на каких сохранениях пройден сценарий. Для новых триггеров особенно важен сейв, в котором условие выполнилось до установки мода.
